# VCCMeasure
VCC Measure — App Android de medições em Kotlin e Jetpack Compose. Inclui régua, fita métrica ARCore, distâncias, alturas, áreas, volumes, ângulos, nível, inclinómetro, bússola, sonómetro, luxímetro, altímetro, velocímetro GPS, vibrações, medições por foto, calibração, conversão de unidades, projetos, histórico e exportação PDF/CSV/JSON.
